## 8. 부록 (Appendix)

### 8.1 용어 정의

| 용어 | 정의 |
|------|------|
| 정밀도 (Precision) | TP / (TP + FP): 양성으로 예측한 것 중 실제 양성의 비율 |
| 재현율 (Recall) | TP / (TP + FN): 실제 양성 중 올바르게 예측한 비율 |
| F1 Score | 2 × (Precision × Recall) / (Precision + Recall) |
| IoU | Intersection over Union: 객체 감지 정확도 지표 |
| mAP | Mean Average Precision: 여러 클래스의 평균 정밀도 |
| FPS | Frames Per Second: 초당 처리 이미지 수 |
