## 1. 문제 정의 (Problem Definition)

### 1.1 현재 상황 (As-Is)

**현장 설명**

한국정밀부품의 엔진 커버 생산라인(Line-3)에서는 알루미늄 다이캐스팅 제품의 표면 결함을 6명의 검사원이 육안으로 검사하고 있습니다. 하루 3교대(8시간씩) 운영 중이며, 각 교대당 2명이 검사를 담당합니다.

주요 문제점:
- 야간 교대 시 검사원 집중력 저하로 불량 검출률이 주간 대비 **18% 낮음**
- 검사 속도 한계로 생산 속도를 따라가지 못해 **간헐적 라인 정체 발생**
- 숙련 검사원 퇴직 후 신입 교육에 **3~6개월 소요**
- 연간 고객 클레임 중 **64%가 표면 결함** 관련

**정량적 현황 데이터**

| 지표 | 현재 값 | 단위 | 측정 주기 |
|------|---------|------|----------|
| 불량률 (Defect Rate) | 3.2 | % | 월간 평균 |
| 검사 처리량 | 480 | 개/시간 | 일 평균 |
| 검사 인력 | 6 | 명 | 고정 |
| 연간 불량 손실액 | 약 4.8억 | 원/년 | 연간 |
| 고객 클레임 건수 | 월 14건 | 건/월 | 월간 |
| 재작업(Rework) 비용 | 약 1.2억 | 원/년 | 연간 |

### 1.2 목표 상황 (To-Be)

**해결하고자 하는 핵심 문제**

> 딥러닝 기반 비전 AI 검사 시스템을 도입하여 엔진 커버 표면 결함(스크래치, 기공, 크랙)을 24시간 균일한 정확도로 자동 검출함으로써, 불량률을 3.2%에서 1.5% 이하로 감소시키고 검사 인력을 6명에서 2명(이상 감지 시 확인 담당)으로 재배치한다.

**AI 적용 방향**
- [x] 비전 AI (이미지/영상 기반 품질 검사)

### 1.3 성공 기준 (Success Criteria)

**핵심 KPI**

| KPI | 현재 값 | 목표 값 | 측정 방법 |
|-----|---------|---------|----------|
| 불량 검출 정확도 (Recall) | ~82% (추정) | 97% 이상 | 테스트셋 평가 |
| 오경보율 (False Positive Rate) | - | 3% 이하 | 테스트셋 평가 |
| 처리 속도 | 480개/시간 | 600개/시간 이상 | 현장 실측 |
| 불량률 | 3.2% | 1.5% 이하 | 월간 불량 집계 |
| 시스템 가동률 | - | 99.5% 이상 | 운영 로그 |

**파일럿 성공 판정 기준**

파일럿 기간(8주) 종료 후 아래 조건을 모두 충족하면 성공으로 판정:
1. 테스트셋 기준 불량 검출 Recall 97% 이상
2. 오경보율(False Positive Rate) 3% 이하
3. 실시간 처리 속도 600개/시간 이상
4. 파일럿 7주차 현장 운영 중 시스템 다운타임 없음

## 3. 모델 선택 및 설계 (Model Selection & Design)

### 3.1 AI 접근 방식 선택

**후보 모델 비교**

| 모델 | 장점 | 단점 | 적합성 점수 |
|------|------|------|------------|
| YOLOv8 (객체 감지) | 빠른 추론, 결함 위치 표시 | 소형 결함 검출 어려움 | 7/10 |
| ResNet-50 (분류) | 단순, 학습 빠름 | 결함 위치 파악 불가 | 6/10 |
| **EfficientNet-B4 + CNN** | 정확도/속도 균형, 전이학습 효율 | 중간 수준 복잡도 | **9/10** |
| ViT (Vision Transformer) | 최고 정확도 가능 | 대용량 데이터 필요, 느림 | 5/10 |

**선택 모델**: EfficientNet-B4 기반 분류 모델 + GradCAM 시각화

**선택 이유**:
1. ImageNet 사전학습 가중치로 소량 데이터(4,400장)에서도 높은 성능 기대
2. EfficientNet-B4는 정확도와 추론 속도의 균형이 최적 (ResNet-50 대비 정확도 +3%, 속도 유사)
3. GradCAM으로 결함 위치 시각화 → 검사원이 결과를 신뢰하고 검수 가능
4. 산업 현장 적용 사례 풍부 (벤치마크 데이터 충분)

### 3.2 시스템 아키텍처

```
[산업용 카메라] → [엣지 서버 (GPU)]
                       │
                  [이미지 전처리]
                  (크롭, 정규화)
                       │
              [EfficientNet-B4 추론]
              (30ms 이하 목표)
                       │
              ┌────────┴────────┐
           [합격]           [불량 감지]
              │                  │
    [컨베이어 통과]      [불량 분류 + GradCAM]
                                  │
                    ┌─────────────┤
                    │             │
             [MES 연동]    [모니터 표시]
             (불량 기록)   (검사원 확인)
```

## 5. 파일럿 타임라인 (8주 계획)

### 5.1 전체 일정

```
주차  | 주요 활동                       | 산출물
------|---------------------------------|--------------------------------
1주차 | 킥오프 / 장비 설치              | 개발 환경, 카메라 설치 완료
2주차 | 데이터 수집 및 라벨링 시작       | 초기 2,000장 데이터셋
3주차 | EfficientNet 베이스라인 학습    | 베이스라인 성능 리포트
4주차 | 데이터 증강 + 하이퍼파라미터 튜닝  | 모델 v1 (목표 85% 이상)
5주차 | 엣지 서버 배포 + 통합 테스트     | 통합 테스트 리포트
6주차 | 전체 데이터 학습 + 최종 최적화    | 모델 v2 (목표 97% 이상)
7주차 | 현장 파일럿 운영 (Line-3 병행)  | 7일간 파일럿 데이터
8주차 | 결과 분석 + 최종 보고           | 파일럿 최종 보고서 + 발표
```

### 5.2 주차별 상세 계획

**1주차: 킥오프 및 환경 설정**

| 작업 | 담당자 | 완료 기준 |
|------|--------|----------|
| 개발 서버 GPU 환경 구축 (CUDA, PyTorch) | 이준혁 | torch.cuda.is_available() == True |
| 산업용 카메라 Line-3 설치 | 박소연 + 장비업체 | 테스트 촬영 500장 정상 수집 |
| 라벨링 도구 설정 (CVAT) | 이준혁 | 팀원 3명 접속 확인 |
