## 학습 목표

- 파일럿 설계서 작성 방법론 습득
- AI 도입 ROI 계산 (생산성·품질·원가 기준)

## 최종 산출물

수강생은 본 세션 완료 후 아래를 제출:

1. **파일럿 설계서** (A4 10~15p): 문제정의 → 데이터 전략 → 모델 선택 → ROI → 로드맵
2. **ROI 계산 시트**: 생산성 +X%, 품질비용 -X%, 원가 -X% 근거
3. **발표 자료** (5분): 핵심 의사결정자 대상
